This project implements a geometric racing line optimizer in Python that computes a racing line from a racetrack centerline using iterative normal-offset optimization. The track is represented as a periodic cubic spline, allowing continuous tangent and normal calculations around a closed circuit. Each iteration adjusts points along the track normal based on the local angle bisector of neighboring segments, reducing curvature while constraining the line to remain within the track boundaries. The resulting racing line is then evaluated with a simple vehicle dynamics model that estimates cornering speeds from curvature, propagates acceleration and braking limits around the circuit, and computes an estimated lap time. Output isn't satisfactory as line doesn't fully achieve minimum laptime which can be confirmed visually. Will look towards a different approach in later versions.
